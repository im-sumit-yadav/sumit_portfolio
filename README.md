# Sumit Yadav Portfolio

Static portfolio website ready for Vercel.

## Deploy with GitHub and Vercel

1. Upload `index.html` and `Sumit_Yadav_Resume.pdf` to the root of a GitHub repository.
2. Import that repository in Vercel.
3. Select **Other** as the framework preset.
4. Leave the build command empty.
5. Deploy.

The resume buttons in the website point to `Sumit_Yadav_Resume.pdf`.
