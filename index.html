Context

Contribution

Built Spring Boot microservices and REST APIs using event-driven architecture, reactive programming, and asynchronous workflows.

Engineering focus

Reusable API clients, validation, object mapping, exception handling, logging, and standardised responses.

Operational focus

Traceable states, resilient errors, retries, and recovery paths for integration-heavy journeys.
Engineering note / 02

Identity & document trust

Sensitive onboarding flows need more than connectivity: they need validation, consent, auditability, resilient callbacks, and predictable recovery.

Third-party integrations

Integrated external identity, verification, consent, and digital document services into backend lending workflows.

Asynchronous flows

Implemented callback handling, reconciliation, retries, and failure recovery for integration workflows that do not complete synchronously.

Protection

Applied secure data handling, request validation, audit tracking, and resilient error handling across third-party interactions.

Engineering boundary

External-provider differences were kept behind predictable backend contracts so the rest of the lending workflow could remain easier to reason about.
Engineering note / 03

Adaptive data layer

External contracts vary. Internal systems still need stable structures for analysis, decisions, and long-term maintainability.

Banking data

Delivered consent-based banking-data flows for access to customer-authorised information.

Insights

Transformed statement JSON into income, cash-flow, balance, transaction, and risk inputs for credit decisioning.

Runtime mapping

Integrated GraalJS mappers for client-specific request and response transformations without code commits or redeployment.

Design intent

Keep changing external payloads away from stable domain logic and reduce repetitive client-specific code.
